# 이 프로젝트만의 작업 지침

이 폴더(`dev-process/local/`)는 **이 프로젝트에서만** 쓰는 작업 지침을 두는 곳이다. 에이전트는 작업을 시작할 때 읽는다.
- 예: 이 프로젝트의 화면 규칙, 배포 절차, 외부 API 사용 규칙
- 공유 컴포넌트(dev-process-framework, 그 설치본, glossary 의 사전 시스템)는 여기 지침으로도 바꿀 수 없다 (AGENTS.md 0번).
- 공유 컴포넌트에 바뀌어야 할 점이 있으면 `upstream-requests.md` 에 적는다 -- 소유자가 원본 저장소에서 처리한다.
