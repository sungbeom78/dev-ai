1. Document Ingestion

이 영역은 RAG 파이프라인의 시작점입니다. 직접 입력한 문서나 메모를 PostgreSQL에 원문으로 저장합니다. 아직 검색 가능한 상태는 아니며, 이후 Chunking과 Vector Indexing을 거쳐 RAG 지식 베이스가 됩니다.

2. Documents & Chunks

등록된 문서를 확인하고, 검색 가능한 단위인 chunk로 나누는 영역입니다. Chunk는 긴 문서를 LLM과 Vector Search가 다루기 쉬운 작은 조각으로 분할한 것입니다.

    Selected: -

    3. Semantic Search Lab

    사용자 질문이 어떤 문서 조각을 검색하는지 확인하는 영역입니다. RAG 답변이 이상할 때, 먼저 Search 결과를 확인하면 검색 문제인지 답변 생성 문제인지 분리할 수 있습니다.

    4. RAG Ask Lab

    검색된 chunk를 context로 사용해 LLM 답변을 생성하는 기본 RAG 영역입니다. 응답에는 answer뿐 아니라 sources, provider, model, latency가 함께 표시됩니다.
