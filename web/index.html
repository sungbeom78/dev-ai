    뉴스레터 파이프라인 흐름도

    이 페이지는 단순 뉴스 수집기가 아니라, 최신 AI 개발 레퍼런스를 내 프로젝트에 적용 가능한 지식으로 바꾸기 위한 파이프라인입니다. 수집한 문서는 한국어로 번역/요약되고, RAG 검색에 사용할 수 있도록 Vector DB에 인덱싱됩니다.

    AI Source 등록 ↓ 6시간 단위 또는 수동 Crawl ↓ HTML Fetch ↓ 본문 추출 ↓ Google API 한국어 번역 ↓ 한국어 요약 생성 ↓ Application Note 생성 ↓ PostgreSQL 저장 ↓ Chunk 생성 ↓ Qdrant Vector Indexing ↓ 한글 질문 기반 RAG 조회 ↓ Agent가 적용 가능성/개선 방향 제안
