# 프로젝트 의도 및 채용 포트폴리오 목적

## 프로젝트명
BomTS Dev AI

## 목적
이 프로젝트는 AI 백엔드 개발자 포지션 지원을 위한 포트폴리오로, 3~4일의 제한된 시간 안에 개발되었습니다. 단순히 완성된 서비스를 보여주는 것이 아니라, **설명 가능한 구조**와 **설계의 근거**를 명확히 제시하는 데 중점을 둡니다.

## 핵심 원칙
1. **투명성과 설명 가능성**: LangChain과 같은 고수준 추상화 프레임워크에 전적으로 의존하기보다는 RAG의 핵심 파이프라인(Chunking, Embedding, Vector Store, Retriever, Prompt Builder, Answer Generator)을 모듈화하여 직접 구현합니다. 이를 통해 각 단계의 원리와 동작을 이해하고 있음을 증명합니다.
2. **현업 수준의 코드 품질**: 모든 코드는 외부 공개와 면접관의 코드 리뷰를 전제로 작성됩니다. 가독성, 유지보수성, 테스트 용이성을 고려합니다.
3. **지속적인 학습과 기록**: Docker와 Vector DB(Qdrant) 등 학습 중인 기술에 대해서는 겪었던 문제, 고민한 점, 해결 과정 등을 `docs/learning` 디렉터리에 상세히 기록합니다.
4. **보안 및 프라이버시**: 전 직장의 내부 자료, 개인정보, 특정 투자 추천 데이터 등 민감한 정보는 절대 포함하지 않습니다. 설정 파일(.env)은 `.env.example`을 통해서만 구조를 공유합니다.

## 개발 범위 (MVP)
- **FastAPI**를 이용한 비동기 API 서버
- **PostgreSQL**을 활용한 메타데이터 및 상태 관리
- **Qdrant**를 이용한 벡터 데이터베이스 구축 및 유사도 검색
- **Docker Compose**를 이용한 전체 시스템의 컨테이너화 및 손쉬운 배포
