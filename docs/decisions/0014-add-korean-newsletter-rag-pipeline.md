# 0014. Add Korean Newsletter RAG Pipeline

## Context
실제 AI 엔지니어링 랩을 운영하려면 사용자가 수동으로 문서를 입력하는 구조를 벗어나, 자동으로 양질의 문서를 확보하고 이를 지식 베이스화해야 합니다.
또한 수많은 해외 AI 개발 트렌드(블로그, 릴리스 노트 등)를 한국어로 번역/요약하여 편하게 검색하고 열람할 수 있는 구조가 필요했습니다.

## Decision
문서 수집(Crawling) -> 번역(Translation) -> 저장(Storage) -> Chunking -> Vector Indexing -> 질의응답(RAG)까지 이어지는 전체 파이프라인을 구축합니다.
- Google API를 활용해 영어 원문을 한국어로 번역하고 요약하여 저장소에 적재합니다.
- 이렇게 번역된 본문과 요약을 기준으로 Qdrant에 인덱싱하며, 사용자가 한글로 질문하면 한글로 답변받도록 구현합니다.
- 6시간 단위로 외부 소스를 크롤링하는 스케줄러(cron 또는 스크립트 기반)를 도입하여 최신 상태를 유지합니다.

## Consequences
- 해외 트렌드를 실시간으로, 그리고 언어 장벽 없이 파악할 수 있는 실질적인 유틸리티가 생깁니다.
- 데이터 ETL 과정을 AI 파이프라인과 접목시킴으로써, 데이터 엔지니어링 역량을 어필할 수 있는 구조가 완성됩니다.
- 한글 기반의 Agent 라우팅 및 질의응답 기능으로 시스템의 실사용 가치가 대폭 향상됩니다.
