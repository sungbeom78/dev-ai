# 도메인 중립적 AI 포트폴리오 원칙

## 1. 개요
본 RAG(Retrieval-Augmented Generation) 시스템인 "BomTS Dev AI"는 트레이딩이나 투자 추천과 같은 특정 금융 산업 도메인에 종속된 애플리케이션이 아닙니다. 이 프로젝트는 **범용적인 AI Backend 아키텍처**를 구성하고 구현하는 능력을 증명하기 위한 포트폴리오 목적입니다.

## 2. 샘플 데이터 정책
- 데이터 파이프라인(Ingestion), 임베딩, 그리고 Qdrant 검색을 검증하기 위해 사용되는 샘플 문서는 다음으로 제한합니다:
  - 본 프로젝트의 개발 가이드 및 구조를 설명하는 마크다운 문서들
  - 시스템 아키텍처 및 의사결정 기록 (ADR)
  - 학습 로깅 및 트러블슈팅 자료
- 이외의 전 직장 내부 기술 문서, 자사 서비스 데이터, 기타 저작권이나 보안 문제가 될 수 있는 모든 데이터는 철저히 배제합니다.

## 3. 기능 제한 구역
- 주식 매수/매도 타이밍 판단
- 투자 종목 추천 필터링
- 금융 자문 및 개인화된 자산 관리성 기능
- 위 항목들과 관련된 데이터 처리 로직은 모두 본 프로젝트 범위에서 제외되며, 오로지 "범용 문서 검색 및 질의응답(Q&A)" 이라는 도메인 독립적 RAG 기능에 집중합니다.
