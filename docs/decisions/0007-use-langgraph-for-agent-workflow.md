# LangGraph를 활용한 Agent Workflow 도입

## 1. 배경
Phase 6에서는 사용자의 질문 의도에 따라 RAG를 탈지, 아니면 시스템 안내나 예외 처리를 할지를 결정하는 분기 로직이 필요했습니다.

## 2. 의사결정: LangGraph 사용
단순한 `if/elif/else` 문으로 라우팅을 구현할 수도 있었으나, **LangGraph** 프레임워크를 도입했습니다.
- **가독성 및 유지보수성**: 상태(State)의 변화와 노드 간의 흐름이 명시적으로 코드에 드러나서 면접 및 포트폴리오 설명 시 아키텍처를 설명하기 용이합니다.
- **확장성**: 현재는 단일 분류기에 의존하는 작은 워크플로우지만, 나중에 여러 LLM Agent가 서로 결과를 검증하는 Multi-Agent 구조로 진화할 때 코드를 갈아엎지 않고 자연스럽게 노드를 추가할 수 있습니다.

## 3. 결론
LangGraph의 StateGraph 객체를 통해 빠르고 직관적인 워크플로우를 구축했으며, 이를 통해 "범용 AI 백엔드"로서 파이프라인 제어 기술을 입증합니다.
