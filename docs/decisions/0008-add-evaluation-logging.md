# 평가 로깅 및 피드백 기능 도입

## 1. 배경
단순히 "동작하는" 데모를 넘어, "운영 가능한" AI 서비스 구조를 포트폴리오에 담기 위해, 사용자의 질문부터 최종 답변, 그리고 피드백까지의 전체 사이클을 기록하는 기능이 필요했습니다.

## 2. 결정 내용
PostgreSQL 기반의 RDBMS 구조에 `AskLog`, `AskSourceLog`, `FeedbackLog` 테이블을 추가하여, `/ask` 및 `/agent/ask` API 호출 시 자동으로 로깅을 수행하고 고유한 `ask_log_id`를 반환하도록 설계했습니다.

## 3. 의의 및 향후 확장
이 "운영 관찰 가능성(Observability)"의 확보는 실무에서 AI 서비스를 고도화하기 위한 필수 기반 작업입니다. 
MVP 단계를 넘어서면 다음과 같이 확장될 수 있습니다:
- Failed Case Dashboard 구축 (👎 피드백 집중 분석)
- 프롬프트/모델 버전 관리 및 A/B 테스트 기반 성과 비교
- LangSmith나 Datadog 등 전문 트레이싱 도구와의 연동
