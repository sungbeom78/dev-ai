# 웹 크롤링 정책 (Web Crawling Policy)

BomTS Dev AI 시스템은 자동화된 지식 수집(AI Trend Pipeline)을 위해 웹 크롤링을 수행합니다. 
이 프로젝트는 개인 학습 및 공개 포트폴리오를 목적으로 하며, 타 사이트에 피해를 주지 않기 위해 다음과 같은 엄격한 크롤링 정책을 준수합니다.

## 기본 원칙

1. **공개된 페이지 중심**
   - 로그인이나 인증이 필요한 페이지는 수집하지 않습니다.
   - 유료 콘텐츠(Paywall)를 우회하는 기술을 사용하지 않습니다.

2. **로봇 배제 표준 (Robots.txt) 존중**
   - 크롤링 대상 사이트의 `robots.txt`를 확인하고 수집이 금지된 경로는 제외합니다.
   - (참고: 현 MVP 단계에서는 명시적으로 우회 기술을 쓰지 않으며, 차단될 경우 수집을 포기합니다.)

3. **요청 속도 제한 (Rate Limiting)**
   - 동일 도메인에 대한 과도한 병렬 요청(DDoS 형태)을 발생시키지 않습니다.
   - 배치 작업 시 요청 사이에 적절한 대기 시간(Delay)을 둡니다.

4. **출처의 보존 및 명시**
   - 수집된 모든 데이터는 반드시 원문 URL 출처(`source`)를 함께 저장합니다.
   - RAG 응답을 제공할 때, 답변의 근거가 된 출처 링크를 명확히 사용자에게 제공합니다.

5. **목적 제한**
   - 수집된 데이터는 영리 목적의 재배포가 아닌, "AI 엔지니어링 지식 베이스 구축" 이라는 연구 및 포트폴리오 시연 용도로만 활용됩니다.
