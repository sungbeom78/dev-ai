# AI 관찰 가능성 (Observability) 기초

AI 서비스, 특히 LLM 기반 애플리케이션 운영 시에는 전통적인 웹 백엔드의 CPU, 메모리, API 응답 시간 외에도 모델 특유의 데이터들을 모니터링해야 합니다. 
Phase 7에서 저장하기 시작한 주요 지표들의 의미는 다음과 같습니다:

- **Latency (latency_ms)**: 질문부터 최종 답변 텍스트 생성까지 걸린 시간입니다. LLM 서비스의 체감 품질을 결정하는 가장 중요한 성능 지표입니다.
- **Provider & Model**: 어떤 LLM 벤더(OpenAI, Local 등)의 어떤 모델을 사용했는지 기록합니다. 향후 A/B 테스트나 벤더 교체 시 비용/성능 분석의 기준이 됩니다.
- **Intent**: LangGraph Agent가 파악한 사용자의 의도입니다. 사용자들이 주로 어떤 목적으로 시스템을 찾는지 통계적으로 분석할 수 있습니다.
- **Sources & Retrieval Count**: 답변의 근거로 사용된 문서와 청크의 개수입니다. 검색된 소스가 전혀 없었는데 답변이 생성되었다면 Hallucination(환각)을 의심해야 합니다.
