# Prompt Building 전략

## 1. 프롬프트의 역할
LLM은 본질적으로 다음 단어를 예측하는 모델입니다. RAG에서 LLM에게 "문서를 읽고 답해라"라는 명확한 지시를 내리려면, 적절한 구조의 텍스트(프롬프트)를 만들어 주어야 합니다.

## 2. Context 주입 및 가드레일(Guardrail)
단순히 질문만 넘기면 LLM은 자신이 학습한 파라미터 내의 환각(Hallucination) 정보에 의존할 수 있습니다. 
이를 막기 위해 본 프로젝트의 `PromptBuilder`는 다음과 같은 규칙(가드레일)을 프롬프트에 명시합니다.
1. "주어진 문맥(Context)을 기반으로 대답할 것"
2. "문맥에 없으면 모른다고 대답할 것 (사실을 지어내지 말 것)"
3. "출처를 바탕으로 답변할 것"

## 3. 효과
이러한 명확한 지시문 템플릿과 결합함으로써, 어떠한 LLM 모델을 연동하든 RAG 본연의 목적에 충실한 "근거 기반의 정보 검색 및 요약"이라는 일관된 출력을 기대할 수 있습니다.
