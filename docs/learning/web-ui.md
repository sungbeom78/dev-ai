# Web UI를 통한 RAG 시각화

## 1. 개요
Phase 5에서는 Nginx를 사용하여 포트 8771에 간단한 Web UI를 배포했습니다. 
이 UI는 트레이딩이나 투자에 특화되지 않은, 순수한 "RAG 흐름"을 학습하고 모니터링하기 위한 대시보드입니다.

## 2. 왜 Web UI가 필요한가?
cURL이나 Swagger(FastAPI 내장)만으로도 API 동작을 검증할 수는 있습니다. 하지만 다음과 같은 한계가 있습니다.
1. **흐름(Flow)의 파편화**: 문서가 등록되고, 청크로 쪼개지고, 임베딩되어 Qdrant에 저장된 후, 최종적으로 검색되어 프롬프트로 들어가는 일련의 과정을 연속적으로 확인하기 어렵습니다.
2. **시각적 컨텍스트 부족**: LLM이 반환하는 JSON 구조는 가독성이 떨어지며, "어떤 청크"가 "어떤 스코어"로 선택되었는지 직관적으로 이해하기 힘듭니다.

## 3. 학습 효과
이 Web UI를 통해 사용자는 다음과 같은 학습 효과를 얻습니다.
- 문서가 입력되었을 때 청킹 단위(Chunking)가 어떻게 나뉘는지 시각적으로 확인합니다.
- 특정 쿼리로 검색했을 때 Vector DB가 반환하는 유사도 스코어(Score)의 변화를 실시간으로 테스트합니다.
- 최종적으로 RAG Ask 과정에서 선택된 Provider(Mock vs OpenAI)와 Latency를 확인하며 병목 구간을 유추해볼 수 있습니다.
