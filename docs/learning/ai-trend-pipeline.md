# AI 트렌드 파이프라인 (AI Trend Pipeline)

## 도입 배경 (Phase 8)
지금까지의 RAG 시스템은 사용자가 텍스트를 직접 입력해야만 지식을 저장할 수 있었습니다. 
하지만 AI 백엔드 도메인은 매주 새로운 프레임워크와 모델, 관련 논문이 발표될 정도로 변화가 빠릅니다. 수동 문서 등록만으로는 시스템을 실질적인 "지식 베이스(Knowledge Base)"로 활용하기 부족합니다.

## 파이프라인 구조
AI 트렌드 파이프라인은 자동화된 지식 수집 및 적재 구조입니다.

1. **Source Registry**: 크롤링할 대상 블로그나 사이트(예: Hugging Face Blog, LangChain Blog)를 등록합니다.
2. **Crawler / Extractor**: URL에서 HTML을 가져오고(`trafilatura`, `BeautifulSoup` 사용), 본문 텍스트와 메타데이터(제목, 작성일 등)를 추출합니다.
3. **Normalizer**: 추출된 텍스트를 문서(`Document`) 형태로 정규화하여 DB에 저장합니다.
4. **Indexer**: 기존의 청킹(Chunking) 및 임베딩 로직을 거쳐 Vector DB(Qdrant)에 저장됩니다.

## 워크플로우 연계
이렇게 적재된 데이터는 기존의 LangGraph 기반 Agent 워크플로우에서 자연스럽게 조회할 수 있습니다. 
사용자가 "최근 오픈소스 LLM 트렌드는 어때?" 라고 질문하면, 에이전트는 최신 크롤링된 문서들을 검색하여 기반 지식으로 답변을 생성합니다.

이러한 수집-처리-조회 파이프라인은 실제 기업의 AI 플랫폼이 외부 지식을 통합하는 방식과 동일한 아키텍처를 보여줍니다.
